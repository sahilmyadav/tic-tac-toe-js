# Tic Tac Toe Game

A simple two-player Tic Tac Toe game built with plain HTML, CSS and
JavaScript. No build step and no dependencies — just open it in a browser.

## Features

- Two-player game on the same screen
- Win and draw detection with a result message
- Restart button to play again

## How to Run

Open `Index.htm` in any browser:

```bash
# macOS
open Index.htm

# or just double-click the file
```

## Files

```
Index.htm   Game page
script.js   Game logic
stryle.css  Styling (original file name kept as-is)
```
